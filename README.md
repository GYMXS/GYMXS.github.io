Aplicacion web, proximamente aplicacion de escritorio y de movil, para profesores, que por el momento mi objetivo es que ayude a mejorar a organizarse mejor con las notas de sus alumnos, con una interfaz sencilla,
con un diseño con colores sencillos y frescos. 
Mas adelante se quiere que el usuario pueda tener una cuenta para poder asi recordar sus cambios y no depender tanto de la copia de seguridad; tambien se quiere agregarle mas seguridad, para que sea rentable poder
tener esa cuenta; mejorar el rendimiento para que se pueda usar lo mejor posible en pc, movil y laptop.
Tambien se espera que el usuario pueda decidir que evluaciones pesan mas que otras
Tambien en el futuro se quiere empezar a usar frameworks, para poder hacer mas entendible el codigo y mas accesible
